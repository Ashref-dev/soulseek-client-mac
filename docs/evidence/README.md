# Native verification evidence

Screenshots in this folder are captured from the running macOS application, not design mockups. Captures may use the loopback development fixture or owner-authorized live Soulseek searches; the corresponding verification note distinguishes the source.

No credentials, private recordings or production conversations should be included. `scripts/native-qa.swift` drives native accessibility controls and captures only Arpeggio's window.

Live account checks are recorded separately from fixture results. Secure fields and private conversations must remain redacted; generated captures are ignored by Git.
