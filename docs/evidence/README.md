# Native verification evidence

Screenshots in this folder are captured from the running macOS application, not design mockups. Any populated network screens use the repository's loopback-only development server and an actual Swift peer sharing generated original WAV audio.

No credentials, private recordings or production conversations should be included. `scripts/native-qa.swift` drives native accessibility controls and captures only Arpeggio's window.

Live Soulseek account interoperability is a separate gate and is not established by these fixtures.
